# LightTodo 功能状态

- 当前代码版本：`0.3.3`
- 最新状态核对：2026-08-07
- 核对依据：当前 `main` 分支的前端入口、Tauri 命令、数据库结构、同步实现和自动化测试

本文只记录当前代码中可实际使用和尚未完成的能力，不把未完成事项预先绑定到版本号。已发布版本的变化请查看 [CHANGELOG](../CHANGELOG.md)。

## 已完成

| 功能领域 | 当前实现 |
| --- | --- |
| 待办管理 | 创建、连续新建、编辑、自动保存、完成、恢复和删除 |
| 编辑体验 | 多行输入、Enter 快速创建、空白草稿清理和基础 Markdown 渲染 |
| 优先级 | 低、中、高三级优先级切换与排序 |
| 截止时间 | 日期时间选择、今日智能分组、逾期时长显示和完成归档 |
| 分组 | 自定义分组创建、重命名、删除、排序、折叠和待办移动 |
| 密码待办 | 可配置密码生成器、AES-256-GCM 本地加密和跨设备 vault 同步 |
| 本地存储 | SQLite 持久化、数据库迁移、标签关联字段和同步删除墓碑 |
| 本地备份 | 设置中心提供独立入口；通过系统文件对话框导出/导入完整 JSON；导入校验、事务替换和失败回滚 |
| WebDAV | 配置与连接测试、双向同步、单向上传、单向下载和五分钟自动同步 |
| 同步安全 | manifest 增量索引、SHA-256 哈希、ETag 条件写入、冲突合并和删除传播 |
| 桌面窗口 | 窗口置顶、位置尺寸记忆、托盘显示/隐藏和单实例启动 |
| 设置中心 | 常规设置、WebDAV 配置、本地备份、关于页面和应用内更新 |
| 跨平台 | Windows NSIS、macOS 通用架构 DMG、Credential Manager 与 Keychain |
| 自动更新 | 检查、签名验证、下载、安装和重启 |
| 自动化测试 | Vitest/React Testing Library、Playwright 框架和 Rust 单元测试 |

## 尚未完成

| 功能领域 | 当前情况 |
| --- | --- |
| 标签管理 | 数据模型、数据库和同步字段已经存在，但当前主界面没有标签编辑、管理和筛选入口 |
| 颜色标记 | 数据字段和旧组件基础已经存在，但当前主界面没有颜色选择入口 |
| 全文搜索 | 后端查询、store 和组件基础已经存在，但尚未接入当前主界面 |
| 离线操作队列 | 尚未提供断网期间的持久化重试队列和可视化状态 |
| 透明窗口与中文输入 | 为保证 IME 正常输入，当前继续使用不透明窗口 |
| 深色模式 | 尚未实现主题切换和完整深色样式 |
| 回收站 | 删除后直接进入同步删除流程，没有软删除列表和恢复期限 |
| 子任务 | 尚未实现父子待办关系和子任务进度 |
| 提醒与重复任务 | 尚未接入桌面通知、提醒调度和重复规则 |
| 快捷键系统 | 尚未提供可配置的全局或应用内快捷键 |
| 同步历史 | 尚未提供多设备同步日志和历史版本查看界面 |
| 附件 | 尚未支持图片或其他文件附件 |
| 待办模板 | 尚未提供模板创建和快速套用 |
| 完整数据加密 | 当前仅密码待办的敏感标题加密，普通待办和本地备份不是全库加密 |
| Linux 凭据存储 | Linux 尚未接入对应系统凭据服务，WebDAV 密码和密码待办能力暂不完整 |

## 维护规则

- 功能只有在当前主界面可访问、后端路径可用且基本验证通过后，才列入“已完成”。
- 仅有数据字段、未接线组件或实验代码的功能仍列入“尚未完成”。
- 发布版本号和发布时间只在 CHANGELOG 与发布流程文档中维护。
